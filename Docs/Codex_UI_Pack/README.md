# Codex UI Pack

This pack contains the complete UI visual reference set and implementation brief for Codex.

## Give Codex
- `MASTER_PROMPT.md`
- `UI_OVERVIEW.png`
- the entire `references/` folder

## Best workflow
Place this folder inside the game repository (for example `/docs/ui-reference/`) so Codex can inspect both the project and the references. Then paste the contents of `MASTER_PROMPT.md` into Codex and ask it to work directly in the repository.

Do not ask Codex to rebuild the whole game from scratch. The prompt explicitly tells it to preserve existing gameplay and integrate the UI with the current systems.
